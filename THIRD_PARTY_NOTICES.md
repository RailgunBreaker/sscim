**One trap worth recording, because it produced a false finding.** A naive
walk over every `package.json` under `node_modules` reports an
unknown-licence dependency called `beep-boop@1.2.3`. It does not exist: it
is a test fixture inside `github-from-package`
(`test/a.json`, `example/package.json`). The audit script therefore
excludes fixture, example, test, spec and benchmark directories, and says
so in its output. A compliance report that counts fixtures is not a
compliance report.

### 1.1 What this means for a proprietary release

All present licences are **permissive**. None requires disclosing the
source of this project, none imposes reciprocal licensing on derivative
works, and none restricts commercial use. The obligations that do apply are
**attribution** and, for Apache-2.0, **preservation of NOTICE files** and
the terms of its patent grant.

**Zero copyleft findings** was checked, not assumed: the scan flags
`GPL`, `AGPL`, `LGPL`, `MPL`, `EPL`, `CDDL`, `CC-BY-SA`, `SSPL`, `OSL` and
`EUPL`, and found none.

The server findings are transitive through Express:

- `body-parser` ≤ 1.20.6 — denial of service when an invalid limit value
  silently disables size enforcement (GHSA-v422-hmwv-36x6).
- `qs` 2.2.5 – 6.15.3 — array-limit bypass via bracket-key comma parsing
  (GHSA-x5fp-wj9c-mxmx), and denial of service via attacker-controlled
  `isBuffer` (GHSA-4mjr-xmp4-gh2g).

A fix is available via `npm audit fix`. **It has deliberately not been
applied in this pass**, because it changes runtime dependency versions and
this pass is a scientific-correctness and release-readiness review, not a
dependency upgrade. It should be applied and re-tested as its own change.

Scope note: the public deployment is a **static site**; the Express server
is used for local editing and optional self-hosting. These findings matter
if and when the API is exposed publicly.

### 3.3 Items to resolve before commercial launch

1. **Market quotes** — confirm redistribution rights, or remove.
2. **Market-share estimates** — confirm that citing values in a commercial
   product is within the originators' terms.
3. **CARTO basemap** — an account key is now required and is being sent.
   Confirm the terms applicable to commercial use and the tile allowance on
   the account the key belongs to, since exceeding it degrades the map for
   every visitor.
4. **`caniuse-lite` CC-BY-4.0 attribution** — confirm whether it applies to
   the distributed build.
5. **Generate a shipped attribution list** from the installed tree.

## 4. How this was produced

The licence table was produced by walking the installed `node_modules`
trees of both workspaces and reading each package's declared `license`
field, then flagging copyleft and unknown licences. Vulnerability counts
come from `npm audit --omit=dev` in each workspace. Both are reproducible
from a clean install; neither is transcribed from memory.

**Limitation:** a declared `license` field is not a substitute for reading
the licence text, and this scan does not detect a package whose declared
field disagrees with its bundled licence file. For a commercial launch, run
a dedicated licence-compliance tool and have the result reviewed.
