# SSCIM evidence example

An evidence-backed event begins with a source, not with a score. Record the original URL or official record, date, affected entity, and exact supported claim. Then make a bounded classification: relevant stages, direction, severity rationale, confidence, and uncertainty.

For example, an official export-control notice can support a dated policy event and named technology scope. It may not by itself support a claim about a specific fab’s production loss. Keep those claims separate.

The reviewer compares the proposal with existing event history, rejects duplicates, and approves only claims that fit the evidence. The model then computes a sensitivity result from the reviewed classification; that result remains distinct from the source fact.
