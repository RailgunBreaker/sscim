The recovery observations are generated by 24 controlled synthetic experiments,
each injecting a market-decaying shock into one stage with both propagation directions:
24 stages at offsets 0, 7, 14, 21, 28, 35 days,
3456 observations per replication, with Gaussian noise of standard
deviation 0.02. Parameters start at 0.4, 0.2, 30.
Nelder-Mead minimizes residual sum of squares. Wald intervals require an
invertible sensitivity covariance and an adequate local approximation; Gaussian
noise alone does not guarantee identifiability. Changes to the event dataset
can change the sensitivity design and make intervals unavailable.

## Part B: output stability

Parameters are sampled uniformly within their declared assumption ranges using
a fixed seed. The envelope is the observed span across those draws. It is
**not a confidence interval**, and these three-parameter draws are not the full
uncertainty analysis. See [the public-review report](../../PUBLIC_RESEARCH_REVIEW.md)
and the sensitivity design in docs/benchmarks/v7-sensitivity.json.

## Part C: pipeline regression

The script checks that explicit base parameters equal defaults, structural
values are finite and within [0,10], and two builds over the same snapshot agree
bit-for-bit. It imports the engine's own primitives, so this is a regression
check, not an independent implementation or evidence of real-world accuracy.

## Reproduction and limits

Companion files: validation-results.json, mle_replications.csv, and
mc_robustness_draws.csv. Fixed random seeds are 20260829 and 777. Re-running
against the same snapshot produces identical numerical draws. The generation
timestamp can change. SSCIM_RECOVERY_REPS and SSCIM_RECOVERY_DRAWS can reduce
the counts for local experiments; committed reports use the defaults.

No real disruption outcome is used here. Nothing in this report establishes
external validity, real-world identifiability or calibrated uncertainty.
Every parameter remains an assumption. Calibration requires independently
assembled incident outcomes, holdout evaluation and reported uncertainty.
