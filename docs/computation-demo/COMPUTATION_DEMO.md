# SSCIM computation demo

This compact walkthrough shows the sequence, not a claim of real-world calibration.

1. Select an event or build a scenario with severity, stages, direction, and channel.
2. Age the event from its authoritative date using the 12-day half-life prior.
3. Seed the selected stages.
4. Propagate contributions through declared graph edges until they fall below tolerance.
5. Combine overlapping contributions and aggregate results to countries and companies using snapshot shares/stakes.
6. Display the result with its source, assumptions, and limitations.

The same code path serves historical events, hypothetical scenarios, and company-disruption analysis. Change the input, not the method.

For formulas see [Calculation specification](../calculation.md). For non-technical interpretation see [Public guide](../PUBLIC_GUIDE.md).
