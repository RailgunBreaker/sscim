# 34. Overall Semiconductor Supply-Chain Index

Let stage weights be $\pi_s$.

```math
\sum_s\pi_s=1
```

Then:

```math
SSCIMIndex
=
100
\sum_s\pi_sR_s
```

A company-based version is:

```math
SSCIMIndex
=
100
\sum_i\omega_iR_i
```

where $\omega_i$ may be market-share, revenue, capacity, or systemic-importance weights.
