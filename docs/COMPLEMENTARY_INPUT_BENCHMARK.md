# Equal incoming allocation and complementary inputs

Generated by `node app/scripts/build-complementary-input-benchmark.mjs`. Current model: `sscim-model-v7.1-exposure-robustness`. This is a synthetic counterexample, not empirical validation. The [canonical specification](MODEL_V7_SPEC.md) defines the exposure calculation.

The default downstream multiplier is 0.55; all upstream inputs have maximum declared non-substitutability. Incoming allocations are the existing equal-split fallback. Each case injects one incident jointly and uses downstream propagation only.

For the separate physical thought experiment, one unit of every named input is indispensable for one output unit, with no inventory, substitutes, spare capacity or transport delays. Output is the minimum remaining input availability. This comparison does not change the engine or calibrate its score.

| Case | A incoming allocation | Modeled output-stage exposure | Physical output fraction | Physical output loss |
| --- | ---: | ---: | ---: | ---: |
| One input A; A unavailable | 1.000000 | 0.550000 | 0.000000 | 1.000000 |
| Complementary inputs A+B; only A unavailable | 0.500000 | 0.275000 | 0.000000 | 1.000000 |
| Complementary inputs A+B+C; only A unavailable | 0.333333 | 0.183333 | 0.000000 | 1.000000 |
| Complementary inputs A+B; both unavailable | 0.500000 | 0.550000 | 0.000000 | 1.000000 |
| Complementary inputs A+B; A half available | 0.500000 | 0.137500 | 0.500000 | 0.500000 |

Adding a second unaffected essential input reduces the model's inherited exposure from 0.550 to 0.275, although loss of A still halts physical production in this thought experiment. A third input reduces the model signal again. Equal allocation averages dependency signals; it cannot express a minimum-input bottleneck. Even simultaneous total input outages transmit at most the declared downstream multiplier to the receiver.

The exposure column is a bounded comparative signal, not a production-loss percentage. Real production requires product-specific bills of materials, inventories, substitution and capacity constraints absent here. Equal-split edges therefore remain declared structural assumptions; graph detail can change the signal without changing the hypothetical physical constraint. The semantic tests in `app/src/engine/complementaryInputs.test.js` preserve this distinction.
