# SSCIM：半導体サプライチェーン・インテリジェンス・マップ

SSCIM は、半導体サプライチェーンの中で、ある混乱がどこへ影響し得るかを調べるための説明可能なリサーチツールです。世界地図、製造段階のグラフ、企業の事業領域、履歴イベント、シナリオを一つのモデルで結びます。

## できること

- 重要な材料・装置・製造・後工程・地域の位置を把握する。
- 選択したイベントまたは仮説シナリオについて、モデル上の影響経路を比較する。
- 地図、産業フロー、トポロジーを同時に読み、根拠と前提を確認する。

## 重要な注意

SSCIM の数値は、公開スナップショットと明示された前提から計算された感度です。予測、実測の貿易量、因果関係、企業の損失見通し、投資助言ではありません。

イベントの出典・日付・信頼度・対象段階と、モデルの制約を必ず確認してください。
