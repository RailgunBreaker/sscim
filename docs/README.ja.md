# SSCIM：半導体サプライチェーン・インテリジェンス・マップ

SSCIM は、半導体サプライチェーンの中である混乱がどこへ影響し得るかを調べるための、説明可能なリサーチツールです。世界地図、製造段階のグラフ、施設ネットワーク、企業の事業領域、レビュー済みの履歴イベントを、一つの計算エンジンの上で結びます。

**SSCIM ではないもの:** リアルタイムの売買シグナル、予測エンジン、実測された貿易フローのモデル、投資助言。

## 想定される読者

- **一般の読者** — ある材料・装置メーカー・ファブ・地域が、なぜ自国の枠を超えて重要になり得るのかを理解する。[一般向けガイド（英語）](PUBLIC_GUIDE.md)から。
- **アナリスト・実務チーム** — モデル上のエクスポージャーを比較し、工場と機能センターのあいだの影響経路をたどり、ハザードの影響範囲をスクリーニングする。前提はすべて可視化されたまま。
- **研究者** — ブラックボックスのリスクスコアではなく、再現可能な感応度モデルを検証する。[学術利用ガイド（英語）](ACADEMIC_GUIDE.md)から。
- **コントリビューター** — レビューと監査を経たパイプラインを通じてエビデンスを追加する。[開発者ガイド（英語）](DEVELOPER_GUIDE.md)から。

## なぜ必要か

半導体は世界で最も地政学的に集中した産業です。オランダの一社があらゆる EUV 露光装置を製造し、一つの島が最先端ロジックの大半を生産し、韓国の二社が HBM メモリを支配しています。

既存の産業構造図——業界団体のチャート、研究機関の図解、静的なインフォグラフィック——は「どこに何があるか」を示すのは得意ですが、「何が変わったか」を示すようには作られていません。輸出管理規制が発表されたとき、ファブが停止したとき、どのノードが新たに露出し、影響はどこまで届き、次に何を見るべきか。SSCIM は、信じるしかないスコアではなく、問いただせるエンジンでその空白を埋めます。

## 仕組み

モデルは 7 つの階層にまたがる 24 の生産ステージ——研究/IP、材料、装置、製造、チップ製品、後工程、システム、最終市場——を持ち、宣言された生産依存関係を表す 34 本の有向エッジで接続されています。国別のステージシェアと企業のステークが、その構造の中に実際の活動を位置づけます。

イベントは、選択されたステージにショックを注入します。エンジンは 12 日の半減期でそれを減衰させ、宣言された下流・上流の伝達事前値を用いて到達可能なすべての経路に伝播させ、重なり合う寄与を有界な規則で合成し、結果を集計します。

同一のコードパスが、レビュー済みの履歴イベント・地図上に自分で置くハザード範囲・企業中断分析のすべてを処理します。**変えるのは入力であって、手法ではありません**——これが三者を比較可能にしています。

結果は同期した 4 つのビューに表示されます:

1. **地理ビュー** — 世界地図上のすべての実名工場、それらを結ぶモデル化リンク、そして任意の地点に置けるハザード半径。国別エクスポージャーは本社所在地ではなく生産地理で描かれます。
2. **産業フロー** — ステージレベルの構造と伝播。
3. **トポロジー** — 国 × ステージの機能センターとモデル上の経路。到達可能性・媒介中心性・取り消し可能なノード／エッジ除去に対応。
4. **ファシリティ・プレイグラウンド** — 実名工場を 1 つ選び、その周囲のモデル化ネットワークをたどります。供給元は左、顧客は右、1 ホップでも 3 ホップでも到達可能なすべてでも。展開・畳み込み・中心の置き直し・絞り込み、そして完全な接続表が使えます。すべての接続は**モデル化された工程媒介の関係**であり、確認された出荷・顧客契約・交易路では決してありません。

これらの状態のすべて——ビュー、固定した対象、レビュー日付、そしてプレイグラウンドでの探索全体——は URL に符号化されるため、任意のビューをリンクして再現できます。

どのスコアを使う前にも、説明・出典・信頼度ラベル・前提を必ず確認してください。

## モデルが意図的に分離しているもの

- **構造的脆弱性**（時間不変）と**実務的インパクト**（イベント駆動）。両者を混ぜれば、二つの相容れない理由で動く数値ができてしまいます。
- **エビデンスの質**と**効果の大きさ**。信頼度は規模と並べて報告され、規模に掛け合わされることはありません。
- 企業の**脆弱性**・**貢献度**・**重要度**。三つの異なる問いには、三つの別々にラベル付けされた数値を。
- 下流の**入力依存度**と上流の**売上依存度**。供給者の顧客向け売上シェアは、その顧客の供給者への依存度ではありません。
- **ベースラインの履歴**と**ハザード・オーバーレイ**。ハザード範囲は限定されたスクリーニング仮説であり、現在の読み値に対する比較として示されるだけで、過去を書き換えることはありません。
- **1 つの事象**と**それに関する複数の報道**。異なる事象は単調かつ有界な演算子で累積します。これは独立した事象には正しく、同一事象の繰り返し報道には誤りです。そのため、同じ事象を記述する複数のレコードは採点の前にグループ化され、スコアに算入されるのはちょうど 1 件、残りは続報または復旧報告として、それぞれの出典と評価を保ったまま公開されます。
- **モデル化された関係**と**観測された関係**。このデータセットには、どの工場がどの工場へ出荷したかを記録したものは一切ないため、施設間の接続はどのホップ深度でも「モデル化」と明示されます。

## 重要な注意

SSCIM の数値は、公開スナップショットと明示された前提から計算された感応度です。予測でも、実測の貿易量でも、因果関係でも、企業の損失見通しでも、投資助言でもありません。

伝播係数と一部のステージ判断は**宣言された事前値**であり、方向性として妥当で再現可能かつ検査可能な挙動を生むために選ばれたもので、いかなるデータにも適合させていません。施設単位の生産能力、在庫、部品表、認定、復旧時間のデータはモデルに存在しません。
