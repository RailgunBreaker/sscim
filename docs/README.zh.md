# SSCIM：半导体供应链情报地图

SSCIM 是一个可解释的研究工具，用于探索半导体供应链中的某一扰动可能如何传播。它把世界地图、生产阶段图、企业业务足迹、历史事件和用户情景放入同一模型。

## 可以做什么

- 了解材料、设备、制造、封装和终端市场在供应链中的位置。
- 比较某个已报道事件或假设情景下的模型传播路径。
- 同时阅读地图、产业流程和拓扑图，并查看来源与前提。

## 重要限制

SSCIM 的数值是基于公开快照和明确前提计算出的敏感度，不是预测、实测贸易量、因果证明、企业损失估计或投资建议。

使用结果前，请查看事件来源、日期、置信度、受影响阶段和模型限制。
